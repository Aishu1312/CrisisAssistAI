Narration:


"CrisisAssist AI is not a traditional chatbot. It is built using a multi-agent architecture where specialized AI agents collaborate to solve emergency situations."


"Instead of one AI model generating a response directly, multiple agents work together using a Planner, Worker, and Evaluator workflow."


"The Planner Agent understands the emergency situation and creates an action plan."


"The Worker Agent executes tasks using different tools such as emergency resource search, location intelligence, summarization, translation, and verification."


"Finally, the Evaluator Agent checks the generated response for accuracy, safety, and completeness before delivering it to the user."


"This collaboration allows the system to provide reliable and trustworthy emergency assistance."
